Réplica de la pantalla Transacciones con las mejoras encima. Mismas 14 columnas y mismo wizard de 3 pasos que el sistema real. Datos inventados.

Esto es una maqueta, no el sistema. No hay conexión con la API y ninguna transacción real se toca. Prueben todo: cambien la numeración, pongan y quiten etiquetas, creen un cliente con solo el nombre, inventen etiquetas nuevas en la configuración. Lo que hagan se guarda solo en este navegador. Al final hay un espacio para escribir qué les falta.

Etiquetas:

La opción Bajo el cliente no ensancha la tabla (ya son 14 columnas); Columna propia agrega una columna más. Díganme cuál prefieren.

5 · Configuración de etiquetas

Crear, renombrar, recolorear, activar o borrar. Los cambios se aplican arriba al instante.

¿Dónde viviría esta pantalla? Como una entrada más del grupo Configuración del menú — al lado de «Banner Home», «Blog» y «Permisos de roles» — en la ruta /app/etiquetas, breadcrumb Configuración > Etiquetas, detrás de los permisos tags.view / tags.create / tags.update / tags.delete. Así ventas usa las etiquetas y solo quien administra puede cambiar el catálogo.
EtiquetaColor Cuenta como cliente nuevoActiva En uso

La columna Cuenta como cliente nuevo es la que conecta la etiqueta con los KPIs del día y con el CSV. Solo una etiqueta puede tenerla. Una etiqueta inactiva deja de ofrecerse al registrar, pero no se borra de las transacciones que ya la tenían.

6 · Sus comentarios

Lo más útil es que respondan estas siete, y agreguen lo que falte.

  • ¿Con la numeración que reinicia cada día les basta, o necesitan otra cosa?
  • ¿Prefieren marcar «cliente nuevo» a mano, o que el sistema lo detecte solo (cuando es el primer envío de esa persona)?
  • Las etiquetas: ¿bajo el nombre del cliente o en columna propia?
  • El alta rápida: ¿con nombre solo basta, o necesitan también el teléfono obligatorio?
  • ¿Quién debería poder crear y borrar etiquetas — solo admin, o ventas también?
  • ¿Qué etiquetas usarían de verdad? Créenlas en la configuración y déjenlas ahí.
  • ¿El CSV del día les resuelve el pase al Drive de ventas/marketing?
